# Autocomplete App

A modern React + TypeScript autocomplete component with debounced search, infinite scroll, keyboard navigation, and clean UI built using Mantine and Vite.

---

## 🚀 Features

- 🔍 Debounced search input
- 📄 Infinite scroll (load more on scroll)
- ⌨️ Keyboard navigation (Up / Down / Enter / Esc)
- 🖱️ Mouse hover and click selection
- ❌ Clear button with hover effect
- 🎯 Highlight matched text
- 📦 Generic reusable autocomplete component
- 🎨 Styled using Mantine + Emotion
- ⚡ Fast development with Vite

---

## 📦 Installed Packages

### Dependencies

- **react** – UI library  
- **react-dom** – React DOM renderer  
- **@mantine/core** – UI components  
- **@mantine/hooks** – Useful hooks  
- **@emotion/react** – CSS-in-JS styling  
- **@emotion/styled** – Styled components  
- **@tabler/icons-react** – Icons  

## Setup and Run

1. Clone the repository:
   ```bash
   git clone https://github.com/lilas-apollo/autocomplete-app.git
   npm install
   npm run dev
   ```
